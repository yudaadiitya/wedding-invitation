# Supabase Setup — Daftar Hadir & Buku Tamu

Panduan langkah demi langkah untuk mengaktifkan penyimpanan online (Supabase) pada fitur **Buku Tamu / Daftar Hadir**.

Selama `VITE_SUPABASE_URL` dan `VITE_SUPABASE_ANON_KEY` belum diisi, GuestBook otomatis fallback ke `localStorage` (data hanya tersimpan di browser tamu). Setelah env diisi, semua RSVP tersimpan di database Supabase dan bisa dilihat dari mana saja.

---

## 1. Buat Project Supabase

1. Buka https://supabase.com lalu **Sign up / Sign in** (gratis, bisa pakai akun GitHub).
2. Klik **New Project**.
3. Isi:
   - **Name**: `wedding-invitation` (bebas)
   - **Database Password**: buat password kuat, simpan di tempat aman.
   - **Region**: pilih paling dekat — **Southeast Asia (Singapore)** untuk Indonesia.
4. Klik **Create new project** lalu tunggu ±2 menit sampai status hijau.

---

## 2. Buat Tabel `guestbook`

1. Di sidebar dashboard, buka **SQL Editor** → **New query**.
2. Tempel SQL berikut lalu klik **Run**:

```sql
-- Tabel utama untuk RSVP & ucapan
create table public.guestbook (
  id          bigint generated by default as identity primary key,
  name        text not null check (char_length(name) between 1 and 60),
  message     text not null check (char_length(message) between 1 and 500),
  attendance  text not null check (attendance in ('hadir','tidak_hadir')),
  created_at  timestamptz not null default now()
);

-- Aktifkan Row Level Security
alter table public.guestbook enable row level security;

-- Siapa pun boleh baca daftar ucapan
create policy "anyone can read"
  on public.guestbook
  for select
  using (true);

-- Siapa pun boleh kirim RSVP (insert)
create policy "anyone can insert"
  on public.guestbook
  for insert
  with check (true);

-- Catatan: policy UPDATE & DELETE sengaja TIDAK dibuat,
-- sehingga tamu tidak bisa mengedit atau menghapus ucapan tamu lain.
```

3. Pastikan keluar pesan **Success. No rows returned**.

---

## 3. Ambil Credentials

1. Sidebar → **Project Settings** (ikon gear) → **API**.
2. Copy dua nilai ini:

| Field di Supabase    | Variabel `.env`            |
|----------------------|----------------------------|
| **Project URL**      | `VITE_SUPABASE_URL`        |
| **anon public** key  | `VITE_SUPABASE_ANON_KEY`   |

> ⚠️ **JANGAN** pakai `service_role` key di frontend — itu key admin dan akan bocor ke publik kalau diletakkan di kode browser. Hanya `anon public` yang aman.

---

## 4. Konfigurasi Lokal

1. Di root project:

```bash
cp .env.example .env
```

2. Edit `.env`:

```env
VITE_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...isi.anon.key.di.sini
```

3. Restart dev server:

```bash
npm run dev
```

4. Buka undangan di browser → kirim ucapan test → buka **Table Editor → guestbook** di Supabase. Data harus muncul.

---

## 5. Konfigurasi Production (Vercel)

1. Buka project di Vercel Dashboard → **Settings** → **Environment Variables**.
2. Tambahkan dua variable berikut untuk **semua environment** (Production, Preview, Development):
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
3. Tab **Deployments** → klik tiga titik pada deployment terakhir → **Redeploy** (centang *Use existing build cache* boleh tidak).

> Variabel `VITE_*` di-embed ke bundle JavaScript saat build. Jika diubah, harus redeploy supaya berlaku.

---

## 6. Cara Memantau Daftar Hadir

### Lihat di Dashboard
**Table Editor → guestbook** — tampilan spreadsheet, bisa filter & sort:

- Filter `attendance = hadir` → daftar yang menghadiri.
- Filter `attendance = tidak_hadir` → yang berhalangan.
- Sort `created_at` desc → ucapan terbaru.

### Export CSV
Table Editor → tombol **Export** (pojok kanan atas) → **CSV**.

### Hitung total cepat
SQL Editor:

```sql
select attendance, count(*) as total
from public.guestbook
group by attendance;
```

## 7. Troubleshooting

| Gejala                                              | Penyebab & Solusi                                                                 |
|-----------------------------------------------------|------------------------------------------------------------------------------------|
| Submit gagal, console error `permission denied`     | RLS aktif tapi policy `insert` belum dibuat. Jalankan ulang SQL di langkah 2.     |
| Data masuk di lokal tapi tidak di production        | Env variable belum di-set di Vercel atau belum redeploy.                          |
| `supabase is null` di console                       | `.env` belum dibaca. Pastikan nama variable diawali `VITE_` dan dev server di-restart. |
| Tabel kosong padahal tamu sudah submit              | Kemungkinan masih fallback `localStorage` (env belum aktif saat itu).             |
| Error `check constraint violated`                   | Panjang `name`/`message` melebihi batas, atau `attendance` di luar `hadir`/`tidak_hadir`. |

## 9. (Opsional) Pengamanan Tambahan

Jika ingin lebih ketat, beberapa pilihan:

1. **Rate limit per IP** — pakai Supabase Edge Function sebagai proxy insert.
2. **Captcha** — integrasi hCaptcha/Cloudflare Turnstile di form sebelum insert.
3. **Moderasi** — tambah kolom `approved boolean default false`, ubah policy `select` jadi `using (approved = true)`, lalu approve manual di Table Editor.

Untuk kebutuhan undangan standar, langkah 1–5 sudah cukup aman.
