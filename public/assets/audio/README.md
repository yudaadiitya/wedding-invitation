## 📥 Cara Setup
Lihat panduan lengkap di: **MUSIC_SETUP.md**

### Quick Steps:
1. Download lagu "Perfect" (lihat panduan legal di MUSIC_SETUP.md)
2. Rename menjadi: `background-music.mp3`
3. Taruh di folder ini: `public/assets/audio/`
4. Check file size < 5MB
5. Test: `npm run dev` → Click "Buka Undangan"

## 🎵 File Requirements
- **Format**: MP3
- **Bitrate**: 128kbps (recommended untuk balance size & quality)
- **Duration**: 3-5 minutes (akan loop otomatis)
- **File Size**: < 5MB untuk fast loading
- **Filename**: Harus `background-music.mp3`

## ⚠️ Important
- File musik **TIDAK included** dalam repo (karena copyright)
- Anda perlu download dan tambahkan sendiri
- Lihat **MUSIC_SETUP.md** untuk panduan lengkap download legal
