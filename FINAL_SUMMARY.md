## 🎬 How to Launch

### 1. Test Locally (Recommended)
```bash
# Dev server sudah running di:
http://localhost:5174/

# Atau restart jika perlu:
npm run dev
```

### 2. Deploy to Production
```bash
# Option A: Deploy ke Vercel (Easiest)
# 1. Push ke GitHub
git init
git add .
git commit -m "Wedding invitation Asri & Ayuda"
git push -u origin main

# 2. Kunjungi vercel.com, import repo, deploy!

# Option B: Deploy ke Netlify
# 1. Build
npm run build

# 2. Drag & drop folder 'dist/' ke netlify.com/drop
```

### 3. Share Link
Setelah deploy, share link website ke tamu undangan!
